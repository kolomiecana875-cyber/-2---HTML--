# Детальний посібник по властивостях блоків у CSS

## Вступ

У цьому матеріалі ми розглянемо основні властивості блоків у CSS, які використовуються для створення сучасних веб-сторінок. Для демонстрації ми будемо використовувати два основних типи елементів:

- Блочний елемент `<div>`
- Рядковий елемент `<span>`

## Базова структура для прикладів

```html
<div class="example-block">Блочний елемент</div>
<span class="example-string">Рядковий елемент</span>
```

## Що таке блочна модель?

Блочна модель CSS - це алгоритм розрахунку розмірів кожного окремого елемента сторінки. Вона складається з декількох ключових компонентів, які впливають на загальні розміри елемента.

## Основні компоненти блочної моделі

1. **Width і Height** - ширина та висота контентної області елемента
2. **Padding** - внутрішні відступи від контенту до країв елемента
3. **Border** - рамка по краю елемента
4. **Margin** - зовнішні відступи навколо елемента

### Способи задання padding

```css
.element {
  padding: 20px; /* всі сторони */
  padding: 20px 40px; /* вертикаль | горизонталь */
  padding: 20px 40px 10px; /* верх | горизонталь | низ */
  padding: 20px 40px 10px 30px; /* верх | право | низ | ліво */
}
```

### Окремі властивості для padding

```css
.element {
  padding-top: 20px; /* відступ зверху */
  padding-right: 40px; /* відступ справа */
  padding-bottom: 10px; /* відступ знизу */
  padding-left: 30px; /* відступ зліва */

  padding-block: 20px; /* вертикальні відступи */
  padding-inline: 40px; /* горизонтальні відступи */
}
```

> **Важливо**: Значення padding не може бути від'ємним.

## Зовнішні відступи (margin)

Margin задає величину зовнішнього відступу навколо елемента.

### Способи задання margin

```css
.element {
  margin: 20px; /* всі сторони */
  margin: 20px 40px; /* вертикаль | горизонталь */
  margin: 20px 40px 10px; /* верх | горизонталь | низ */
  margin: 20px 40px 10px 30px; /* верх | право | низ | ліво */
}
```

### Окремі властивості для margin

```css
.element {
  margin-top: 20px; /* відступ зверху */
  margin-right: 40px; /* відступ справа */
  margin-bottom: 10px; /* відступ знизу */
  margin-left: 30px; /* відступ зліва */

  margin-block: 20px; /* вертикальні відступи */
  margin-inline: 40px; /* горизонтальні відступи */
}
```

### Особливості margin

1. **Від'ємні значення**

   - Margin може приймати від'ємні значення
   - Це дозволяє "насувати" елементи один на одного

2. **Значення auto**

   ```css
   .element {
     margin: 0 auto; /* горизонтальне центрування */
   }
   ```

3. **Схлопування відступів (margin collapse)**
   - Відбувається при перетині вертикальних margin
   - Підсумковий відступ дорівнює найбільшому з тих, що перетинаються
   - Працює тільки для блочних елементів

## Рекомендації щодо використання

### Коли використовувати padding:

- Для створення простору між вмістом і межами елемента
- Коли потрібно збільшити клікабельну область елемента
- Для візуального відокремлення вмісту від рамки

### Коли використовувати margin:

- Для створення відстані між елементами
- Для відступів від країв батьківського елемента
- Для горизонтального центрування елементів

### Найкращі практики

1. Задавайте відступи в одному напрямку (зверху вниз та зліва направо)
2. Використовуйте `margin-right` та `margin-bottom` замість `left` та `top`
3. Будьте обережні зі схлопуванням відступів
4. Використовуйте консистентні значення відступів


## Ширина та висота елементів

### Width (ширина)

```css
.element {
  width: 500px; /* фіксована ширина */
  width: 100%; /* відносна ширина */
}
```

#### Особливості:

- Блочні елементи за замовчуванням займають 100% ширини
- Для рядкових елементів width не працює
- Працює для зображень (`<img>`)

### Height (висота)

```css
.element {
  height: 200px; /* фіксована висота */
  height: 50%; /* відносна висота */
}
```

#### Важливо знати:

- За замовчуванням висота підлаштовується під контент
- Фіксована висота може призвести до проблем з переповненням
- Відсоткове значення працює, якщо батьківський елемент має явно задану висоту

### Мінімальні та максимальні розміри

```css
.element {
  min-width: 300px; /* мінімальна ширина */
  max-width: 800px; /* максимальна ширина */
  min-height: 100px; /* мінімальна висота */
  max-height: 400px; /* максимальна висота */
}
```

#### Практичне застосування:

- `max-width` - для адаптивного дизайну
- `min-width` - для збереження читабельності
- `min-height` - для гарантії мінімального простору
- `max-height` - для обмеження розростання елементів

## Box-sizing

### Стандартна модель (content-box)

```css
.element {
  box-sizing: content-box;
  width: 500px;
  padding: 20px;
  border: 1px solid black;
  /* Фактична ширина = 500px + 40px (padding) + 2px (border) = 542px */
}
```

### Альтернативна модель (border-box)

```css
.element {
  box-sizing: border-box;
  width: 500px;
  padding: 20px;
  border: 1px solid black;
  /* Фактична ширина = 500px (включає padding та border) */
}
```

## Overflow (переповнення)

Властивість overflow контролює, що відбувається з контентом, який не вміщується в задані розміри:

```css
.element {
  height: 200px;
  overflow: visible; /* контент видно за межами блоку (за замовчуванням) */
  overflow: hidden; /* контент обрізається */
  overflow: scroll; /* додаються смуги прокрутки */
  overflow: auto; /* смуги прокрутки з'являються за потреби */
}
```

## Display (тип відображення)

### Значення властивості display:

1. **block**

   ```css
   display: block;
   /* елемент стає блочним */
   ```

   - Займає всю доступну ширину
   - Можна задавати розміри та відступи
   - З нового рядка

2. **inline**

   ```css
   display: inline;
   /* елемент стає рядковим */
   ```

   - Ширина за контентом
   - Не можна задавати розміри
   - В один рядок з іншими елементами

3. **inline-block**

   ```css
   display: inline-block;
   /* гібрид блочного та рядкового */
   ```

   - В один рядок з іншими елементами
   - Можна задавати розміри та відступи
   - Ширина за контентом

4. **none**
   ```css
   display: none;
   /* приховує елемент */
   ```
   - Елемент повністю прибирається
   - Місце не резервується
   - Сторінка перебудовується

## Практичні поради

1. **Для відступів:**

   - Використовуйте padding для внутрішніх відступів
   - Уникайте фіксованої висоти, якщо можливо
   - Надавайте перевагу max-width замість фіксованої ширини

2. **Для box-sizing:**

   ```css
   * {
     box-sizing: border-box; /* для всього сайту */
   }
   ```

3. **Для display:**
   - Використовуйте inline-block для навігації
   - block для основних секцій
   - none для динамічного приховування

## Приклад комплексного використання

```css
.card {
  /* Розміри */
  width: 100%;
  max-width: 300px;
  min-height: 200px;

  /* Відступи */
  padding: 20px;

  /* Модель блоку */
  box-sizing: border-box;

  /* Переповнення */
  overflow: auto;

  /* Відображення */
  display: inline-block;
}
```

> **Порада**: Завжди тестуйте свої стилі з різним контентом та на різних розмірах екрану.
