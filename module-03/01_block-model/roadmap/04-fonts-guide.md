# Використання шрифтів у веб-розробці

## `<link>` vs `@import` для Google Fonts

### Чому `<link>` краще?

1. **Швидкість завантаження**
   - `<link>` дозволяє паралельне завантаження з іншими ресурсами
   - `@import` блокує завантаження інших ресурсів

2. **Продуктивність**
   - `<link>` обробляється браузером відразу
   - `@import` вимагає додаткового HTTP-запиту

3. **Контроль**
   - З `<link>` більше можливостей керування завантаженням
   - Можливість використання атрибутів типу `preload`

### Приклади використання

```html
<!-- ✅ Рекомендований спосіб -->
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">

<!-- ❌ Не рекомендований спосіб -->
<style>
@import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap');
</style>
```

## Альтернативні джерела шрифтів

### 1. Безкоштовні ресурси
- **Adobe Fonts** (раніше Typekit)
  - Безкоштовний план з Adobe Creative Cloud
- **Font Squirrel**
  - Безкоштовні шрифти для комерційного використання
- **DaFont**
  - Велика колекція безкоштовних шрифтів
- **Open Font Library**
  - Відкрита бібліотека шрифтів

### 2. Локальне використання шрифтів

```css
@font-face {
    font-family: 'МійШрифт';
    src: url('path/to/font.woff2') format('woff2'),
         url('path/to/font.woff') format('woff');
}
```

### 3. System fonts (безпечний варіант)

```css
body {
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, 
                 Oxygen-Sans, Ubuntu, Cantarell, "Helvetica Neue", sans-serif;
}
```

## Важливі моменти при виборі шрифтів

1. Завжди перевіряйте ліцензію шрифту
2. Використовуйте формати WOFF2 і WOFF
3. Обмежте кількість шрифтів
4. Вказуйте fallback шрифти

## Рекомендації для початківців

1. **Почніть з Google Fonts**
   - Найпростіший і надійний варіант
   - Велика безкоштовна колекція
   - Легке підключення

2. **Використовуйте `<link>`**
   - Краща продуктивність
   - Простіше відлагодження

3. **Обмежтесь 2-3 шрифтами**
   - Покращує швидкість завантаження
   - Робить дизайн більш цілісним

4. **Завжди вказуйте fallback**
   - Забезпечує надійність
   - Покращує користувацький досвід

### Приклад хорошої практики

```html
<!-- У head -->
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&family=Open+Sans&display=swap" 
      rel="stylesheet">

<!-- У CSS -->
body {
    font-family: 'Roboto', -apple-system, BlinkMacSystemFont, sans-serif;
}

h1, h2, h3 {
    font-family: 'Open Sans', Arial, sans-serif;
}
```

## Висновок

При виборі та використанні шрифтів важливо знайти баланс між:
- Естетикою (гарний дизайн)
- Продуктивністю (швидке завантаження)
- Надійністю (коректне відображення)

Google Fonts з використанням `<link>` - найкращий варіант для початківців, але варто знати і про інші джерела та способи підключення шрифтів для різних проєктів.
