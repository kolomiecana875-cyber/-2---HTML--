# Семантика HTML5: Структура сучасних веб-сторінок

## Що таке семантика HTML?

Семантика HTML - це підхід до створення веб-сторінок, при якому HTML-теги використовуються відповідно до їх смислового значення, а не лише для візуального форматування. Це допомагає:
- Пошуковим системам краще розуміти контент
- Браузерам правильно інтерпретувати структуру сторінки
- Програмам зчитування екрану (screen readers) коректно озвучувати вміст
- Розробникам легше розуміти та підтримувати код

## Основні семантичні теги HTML5

### 1. `<header>`
Верхня частина сторінки або секції. Зазвичай містить:
```html
<header>
    <a href="/">
        <img src="logo.png" alt="Логотип сайту">
    </a>
    <nav>
        <!-- Навігаційне меню -->
    </nav>
</header>
```

### 2. `<nav>`
Навігаційне меню сайту:
```html
<nav>
    <ul>
        <li><a href="/">Головна</a></li>
        <li><a href="/about">Про нас</a></li>
        <li><a href="/contacts">Контакти</a></li>
    </ul>
</nav>
```

### 3. `<main>`
Основний контент сторінки. На сторінці повинен бути тільки один `<main>`:
```html
<main>
    <article>
        <!-- Основний контент -->
    </article>
    <aside>
        <!-- Бічна панель -->
    </aside>
</main>
```

### 4. `<article>`
Самостійний, незалежний контент (статті, пости, коментарі):
```html
<article>
    <h2>Заголовок статті</h2>
    <p>Текст статті...</p>
    <footer>
        <p>Автор: Іван Петренко</p>
    </footer>
</article>
```

### 5. `<section>`
Логічний розділ сторінки:
```html
<section>
    <h2>Наші послуги</h2>
    <div class="services">
        <!-- Вміст секції -->
    </div>
</section>
```

### 6. `<aside>`
Додаткова інформація, пов'язана з основним контентом:
```html
<aside>
    <h3>Рекомендовані статті</h3>
    <ul>
        <li><a href="#">Стаття 1</a></li>
        <li><a href="#">Стаття 2</a></li>
    </ul>
</aside>
```

### 7. `<footer>`
Нижня частина сторінки або секції:
```html
<footer>
    <p>&copy; 2024 Назва компанії</p>
    <nav>
        <ul>
            <li><a href="/privacy">Політика конфіденційності</a></li>
            <li><a href="/terms">Умови використання</a></li>
        </ul>
    </nav>
</footer>
```

## Повний приклад семантичної структури

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Семантична структура</title>
</head>
<body>
    <header>
        <a href="/" class="logo">Логотип</a>
        <nav>
            <ul>
                <li><a href="/">Головна</a></li>
                <li><a href="/about">Про нас</a></li>
                <li><a href="/contacts">Контакти</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <h1>Головна стаття</h1>
            <p>Основний текст статті...</p>
        </article>

        <section>
            <h2>Додаткова інформація</h2>
            <p>Текст секції...</p>
        </section>

        <aside>
            <h3>Корисні посилання</h3>
            <ul>
                <li><a href="#">Посилання 1</a></li>
                <li><a href="#">Посилання 2</a></li>
            </ul>
        </aside>
    </main>

    <footer>
        <p>&copy; 2024 Всі права захищені</p>
    </footer>
</body>
</html>
```

## Переваги використання семантичних тегів

1. **Доступність**:
   - Покращена робота з програмами зчитування екрану
   - Краща навігація для користувачів з обмеженими можливостями

2. **SEO**:
   - Пошукові системи краще розуміють структуру сторінки
   - Потенційно вищі позиції в результатах пошуку

3. **Підтримка коду**:
   - Код стає більш читабельним
   - Легше знаходити та виправляти помилки
   - Простіше вносити зміни в майбутньому

## Практичні поради

1. **Використовуйте теги за призначенням**:
   - `<header>` для шапки сайту
   - `<nav>` для навігації
   - `<main>` для основного контенту
   - `<article>` для самостійних блоків контенту
   - `<aside>` для додаткової інформації
   - `<footer>` для підвалу сайту

2. **Уникайте надмірного використання `<div>`**:
   - Використовуйте `<div>` тільки коли немає підходящого семантичного тега
   - Надавайте перевагу семантичним тегам

3. **Правильно структуруйте заголовки**:
   - Використовуйте `<h1>` - `<h6>` в правильному порядку
   - Один `<h1>` на сторінку
   - Не пропускайте рівні заголовків

## Висновок

Семантична розмітка - це не просто гарна практика, а необхідність для створення сучасних веб-сайтів. Вона покращує:
- Доступність сайту
- SEO-оптимізацію
- Читабельність коду
- Підтримку проекту

> **Порада**: Завжди починайте розробку сторінки з планування її семантичної структури, а потім переходьте до стилізації.
