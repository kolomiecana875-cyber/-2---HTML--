# Коротко про головне: Шпаргалка (HTML/CSS Модуль 2)

### 1. Блочна модель та розміри (Box Model)
Блочна модель CSS описує розміри елемента, які складаються з контенту, внутрішніх відступів, рамок та зовнішніх відступів.
*   **`width` / `height`**: Ширина та висота області контенту. Можна задавати фіксовані (`px`) або відносні (`%`) значення.
*   **`min-width` / `max-width`** (та `height`): Обмеження мінімальних і максимальних розмірів (корисно для адаптиву).
*   **`padding`**: Внутрішні відступи (між контентом і рамкою). Збільшують загальний розмір елемента і клікабельну область. Не можуть бути від'ємними.
*   **`margin`**: Зовнішні відступи (відстань між елементами). Можуть бути від'ємними (для накладання) та мати значення `auto` (для центрування блоків по горизонталі). Вертикальні марджіни сусідніх блочних елементів можуть "схлопуватись" (margin collapse).
*   **`box-sizing`**:
    *   `content-box` (за замовчуванням): `padding` і `border` *додаються* до вказаної `width`/`height`.
    *   `border-box` (рекомендовано): `padding` і `border` *включені* у вказану `width`/`height`.

### 2. Типи відображення (Display) та Переповнення (Overflow)
*   **`display: block`**: Займає всю доступну ширину, починається з нового рядка. Можна задавати ширину/висоту та всі відступи. (Напр., `<div>`, `<p>`, `<h1>`).
*   **`display: inline`**: Займає ширину контенту, не переносить рядок. Не можна задати `width`, `height`, а також вертикальні відступи (`margin`, `padding` працюють з нюансами). (Напр., `<span>`, `<a>`).
*   **`display: inline-block`**: Поводиться як рядковий елемент (не переносить рядок), але дозволяє задавати розміри та відступи.
*   **`display: none`**: Повністю приховує елемент (місце на сторінці більше не резервується).

**Переповнення (`overflow`)**:
*   `visible` (за замовчуванням) — контент виходить за межі.
*   `hidden` — контент обрізається.
*   `scroll` — завжди додає смуги прокрутки.
*   `auto` — смуги прокрутки лише якщо контент не вміщується.

### 3. Оформлення блоків
*   **`border`**: Рамка. Синтаксис: `border: {товщина} {стиль} {колір}` (напр., `1px solid black`). Стилі: `solid` (суцільна), `dashed` (пунктир), `dotted` (крапки).
*   **`border-radius`**: Скруглення кутів (напр., `10px`). Значення `50%` робить елемент круглим.
*   **`outline`**: Зовнішній контур, не впливає на розміри елемента. Може мати відступ `outline-offset`.
*   **`box-shadow`**: Тінь елемента. Синтаксис: `зсув-X зсув-Y розмиття розширення колір` (напр., `5px 5px 10px rgba(0,0,0,0.3)`). Може бути внутрішньою (`inset`).
*   **`opacity`**: Прозорість елемента (від `0` до `1`).
*   **`visibility`**: Видимість. На відміну від `display: none`, `visibility: hidden` приховує візуально, але елемент продовжує займати місце.

### 4. Семантика HTML5
Використання семантичних тегів замість `<div>` покращує SEO, доступність (для зчитувачів екрану) та читабельність коду.
*   **`<header>`**: Шапка сторінки або секції.
*   **`<nav>`**: Основне навігаційне меню сайту.
*   **`<main>`**: Головний унікальний контент сторінки (може бути лише один).
*   **`<article>`**: Самостійний, незалежний контент (пост, новина, коментар).
*   **`<section>`**: Логічний розділ або тематичний блок.
*   **`<aside>`**: Додаткова інформація (бічні панелі, банери, пов'язані посилання).
*   **`<footer>`**: Підвал сторінки або секції (копірайт, контакти, навігація внизу).

### 5. Списки
*   **`<ul>` / `<li>`**: Маркований (Unordered) список (порядок неважливий).
*   **`<ol>` / `<li>`**: Нумерований (Ordered) список (порядок важливий).
*   **`<dl>` / `<dt>` / `<dd>`**: Список визначень (термін `dt` та його опис `dd`).

**Стилізація списків (CSS):**
*   **`list-style-type`**: Тип маркера (`disc`, `circle`, `square`, `none` - для приховання маркерів). Для `<ol>`: `decimal`, `lower-alpha`, `upper-roman` тощо.
*   **`list-style-position`**: Розташування маркера (`inside` - всередині текстового блоку, `outside` - назовні).
*   **`list-style-image`**: Маркер-картинка (`url(...)`).
*   **`list-style`** (скорочення): `list-style: {type} {position} {image}`.

*Лайфхак*: Щоб повністю скинути стандартні стилі списку (часто роблять для навігації), використовують:
```css
ul {
  list-style: none; /* прибрати маркери */
  padding-left: 0;  /* прибрати внутрішній відступ */
  margin: 0;        /* прибрати зовнішні відступи */
}
```
