# Завдання 1 - Реалізація HTML-сторінки зі списком пір року

## Опис завдання

Створити HTML-сторінку зі списком пір року, використовуючи вкладені списки для відображення місяців кожної пори року. Кожен місяць повинен мати відповідну іконку.

## Структура проекту

```
task-01/
├── index.html
├── style.css
└── icons/
    ├── winter_16.png
    ├── spring_16.png
    ├── summer_16.png
    └── autumn_16.png
```

## Покрокова інструкція

### 1. Створення базової структури HTML

- Створіть файл `index.html`
- Встановіть заголовок сторінки "Seasons of the Year"
- Додайте базову структуру HTML-документа (doctype, html, head, body)
- Підключіть файл стилів style.css

### 2. Створення списку пір року

- Створіть контейнер для всього контенту
- Додайте заголовок першого рівня "Seasons"
- Створіть ненумерований список (`<ul>`) з класом "seasons-list"
- Додайте чотири елементи списку (`<li>`) з класом "season", по одному для кожної пори року:
  - Winter
  - Spring
  - Summer
  - Autumn

### 3. Додавання місяців до кожної пори року

- Для кожної пори року створіть вкладений ненумерований список (`<ul>`) з класом "months"
- Для зими додайте місяці:
  - December (з іконкою сніжинки)
  - January (з іконкою сніжинки)
  - February (з іконкою сніжинки)
- Для весни додайте місяці:
  - March (з іконкою квітки/рослини)
  - April (з іконкою квітки/рослини)
  - May (з іконкою квітки/рослини)
- Для літа додайте місяці:
  - June (з іконкою сонця/ягоди)
  - July (з іконкою сонця/ягоди)
  - August (з іконкою сонця/ягоди)
- Для осені додайте місяці:
  - September (з іконкою листя)
  - October (з іконкою листя)
  - November (з іконкою листя)

## Вимоги до форматування

- Використання вкладених списків для структурування інформації
- Використання іконок або символів для візуального позначення місяців
- Кольорове оформлення відповідно до пори року:
  - Зима: відтінки синього
  - Весна: відтінки зеленого
  - Літо: відтінки оранжевого/жовтого
  - Осінь: відтінки коричневого
- Використання трикутника (▶) перед назвою кожної пори року
- Правильне вирівнювання та відступи для вкладених елементів

## Результат

Після виконання всіх кроків ви отримаєте HTML-сторінку зі списком пір року, яка має:

- Чітко структуровану ієрархію пір року та місяців
- Візуальне оформлення з використанням іконок та кольорів
- Стилізований список з правильними відступами та маркерами
- Адаптивний дизайн, що добре виглядає на різних пристроях
