# Завдання 2 - Реалізація HTML-сторінки зі змістом статті

## Опис завдання

Створити HTML-сторінку зі змістом статті, використовуючи нумеровані та ненумеровані списки. Зверніть увагу, що у нумерації і тексту різні стилі (колір і жирність).

## Структура проекту

```
task-02/
├── index.html
└── style.css
```

## Покрокова інструкція

### 1. Створення базової структури HTML

- Створіть файл `index.html`
- Встановіть заголовок сторінки "HTML Article Contents"
- Додайте базову структуру HTML-документа (doctype, html, head, body)
- Підключіть файл стилів style.css

### 2. Створення контейнера для змісту

- Створіть контейнер для всього контенту з класом "container"
- Додайте заголовок "Contents" для змісту

### 3. Створення структури змісту

Використовуйте вкладені нумеровані (`<ol>`) та ненумеровані (`<ul>`) списки для створення ієрархічної структури змісту:

1. Створіть нумерований список (`<ol>`) для основних розділів
2. Для кожного підрозділу використовуйте відповідний тип списку:
   - Для основних розділів (I, II, III...) - використовуйте римські цифри
   - Для підрозділів першого рівня (1, 2, 3...) - використовуйте арабські цифри
   - Для підрозділів другого рівня (a, b, c...) - використовуйте літери

### 4. Додавання контенту змісту

Додайте наступні розділи та підрозділи:

```
I. History
   1. Development
   2. HTML versions timeline
      a. HTML draft version timeline
      b. XHTML versions
II. Markup
   1. Elements
      a. Element examples
      b. Attributes
   2. Character and entity references
   3. Data types
   4. Document type declaration
III. Semantic HTML
IV. Delivery
   1. HTTP
   2. HTML e-mail
   3. Naming conventions
   4. HTML Application
V. HTML4 variations
   1. SGML-based versus XML-based HTML
   2. Transitional versus strict
   3. Frameset versus transitional
   4. Summary of specification versions
VI. HTML5 variants
   1. WHATWG HTML versus HTML5
VII. Hypertext features not in HTML
VIII. WYSIWYG editors
IX. See also
X. References
XI. External links
```

### 5. Додавання стилів (CSS)

У файлі `style.css` створіть стилі.

## Вимоги до форматування

- Використання вкладених нумерованих та ненумерованих списків для структурування змісту
- Використання різних типів нумерації для різних рівнів списку:
  - Римські цифри для основних розділів (I, II, III...)
  - Арабські цифри для підрозділів першого рівня (1, 2, 3...)
  - Літери для підрозділів другого рівня (a, b, c...)
- Стилізація тексту:
  - Жирний шрифт для основних розділів
  - Звичайний шрифт для підрозділів
  - Різні кольори для різних рівнів списку
- Правильне вирівнювання та відступи для вкладених елементів

## Результат

Після виконання всіх кроків ви отримаєте HTML-сторінку зі змістом статті, яка має:

- Чітко структуровану ієрархію розділів та підрозділів
- Різні типи нумерації для різних рівнів списку
- Різні стилі тексту (колір і жирність) для різних рівнів списку
- Правильні відступи та вирівнювання для всіх елементів змісту
